# Bayesian Figure Construction - Python Codes

## Overview
These Python scripts are designed to construct the Bayesian figure. Each script targets different scatter plots, allowing detailed visualization of Bayesian analyses. Scripts “Main Bayesian X.py” and “Main Bayesian Z.py” are meant to be run separately.

## Features
- Optimized for parallel execution on up to 200 cores,
- Parameters can be easily varied to customize the plots.
- The figure is saved automatically; it is not displayed during execution.
- For proper operation, please create a folder named ‘./Data Aux/’ in the same directory where the scripts are located. This folder is used for storing intermediate data and auxiliary files.
