# README

This repository contains all the codes used to generate the analytical expressions and the figures found in the manuscript *Quantum error correction for multiparameter metrology* by Mauricio Gutiérrez, Chiranjib Mukhopadhyay, Victor Montenegro, and Abolfazl Bayat.

# Overview

There are 3 folders:

- **MathematicaFiles/** contains all the Mathematica notebooks used to generate the analytical expressions found in the paper.
- **GeneratingMainTextFigures/** contains all the MATLAB scripts used to generate the figures in the main text.
- **BayesianAnalysis/** contains the Python scripts used for the Bayesian analysis and to generate the figures in the Methods section.
